# Preorder Herd-Event Food Systems

## System Design

- One public release slot per week, same weekday, same time.
- One visible but truthful capacity number based on production constraints.
- One group-buy mechanism: office list, family tray, WhatsApp cohort, or VIP club.
- One payment cutoff before procurement/prep.
- One waitlist that decides the next release.

## Event Types

| Event | Best dish structure | Mechanism | Monetization |
|---|---|---|---|
| Office Herd Lunch | bowls, sauced mains, trays | admin collects names | per-head bundle + delivery fee |
| Family Tray Allocation | braises, roast meats, curries | 20 tray cap | deposit + premium add-ons |
| Sauce Drop | rubs, dips, marinades | batch count | jars, sachets, refill club |
| Safari Lounge Insider Plate | premium fusion special | VIP first access | high-margin limited item |
