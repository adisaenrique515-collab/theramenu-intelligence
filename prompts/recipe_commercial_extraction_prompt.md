# Recipe Commercial Extraction Prompt

Use this prompt when manually reviewing extracted candidates:

Treat each recipe as a commercial data point. Do not summarize the recipe. Identify what it can become: a menu item, catering tray, scarcity drop, sauce/component, consulting insight, or software record. Preserve copyright boundaries by extracting metadata, business logic, and original derivative ideas rather than copying protected recipe text.

Required output fields match `data/master/recipe_commercial_intelligence.csv`.
